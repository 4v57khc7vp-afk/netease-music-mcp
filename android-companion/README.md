# 网易云播放伴侣（Android）

读取 Android 系统 MediaSession 暴露的网易云播放元数据，每秒向私人 MCP 上报一次：

- 歌名、歌手与可用时的歌曲 ID；
- 播放位置、总时长、播放/暂停状态；
- 上报时间与稳定的设备 ID。

应用不接收网易云账号密码，不读取或保存 `MUSIC_U`。服务器凭据应使用控制台生成的、仅勾选 `player:control` 的设备 Token。

## 构建

使用 Android Studio 打开本目录并生成 APK。安装后：

1. 填写服务器根地址（例如 `https://music.xminute.help`）和设备 Token；
2. 点击“开启通知使用权”，只为本应用打开权限；
3. 在系统电池设置中允许后台运行；
4. 打开网易云播放歌曲，回到伴侣查看“上报成功”。

部分网易云版本不会在 MediaSession 中暴露数字歌曲 ID。此时仍会上报歌名和歌手，服务器可以进行匹配；最终效果需要在目标手机上实测。
